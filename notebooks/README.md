# Notebooks

Research and experimentation notebooks organized by task.

## Structure

- **`baseline/`** — baseline model evaluation (seq2seq).
- **`data/`** — query collection and triplet mining.
- **`evaluation/`** — evaluation of TF-IDF, baseline, and SPARQLCE models.
- **`finetuning/`** — dataset creation and finetuning for binary classifiers and contrastive models.
- **`robustness/`** — perturbation datasets and robustness evaluation.
- **`training/`** — model training pipelines.
- **`visualization/`** — embedding space visualization and analysis.
