# Evaluation for Research Question 1 (RQ1)

This folder contains notebooks and datasets for evaluating Research Question 1 (RQ1).

## Contents
- **DBpedia/**: Contains evaluation notebooks specific to DBpedia.
- **Wikidata/**: Contains evaluation notebooks specific to Wikidata.

## How to Run

1. **Set up the environment**:
   - Ensure all dependencies are installed by running:
     ```bash
     pip install -r requirements.txt
     ```

2. **Navigate to the notebook folder**:
   ```bash
   cd notebooks/evaluation-RQ1
   ```

3. **Run the notebooks**:
   - Open the desired notebook (e.g., `06_eval_sparqlce_dbpedia.ipynb`) in Jupyter Notebook or VS Code.
   - Execute the cells sequentially to reproduce the results.

4. **Datasets**:
   - Ensure the required datasets are available in the `datasets` folder.

## Notes
- Results will be saved in the respective notebook folders.
- Modify paths in the notebooks if running from a different directory structure.
