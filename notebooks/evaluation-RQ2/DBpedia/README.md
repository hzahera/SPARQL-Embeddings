# Robustness Evaluation (DBpedia)

This directory contains robustness evaluation notebooks for the DBpedia dataset.

## Contents
- `08_visualize_robustness_dbpedia.ipynb`: Visualizes robustness evaluation results for DBpedia.

## How to Run

1. **Set up the environment**:
   - Ensure all dependencies are installed by running:
     ```bash
     pip install -r requirements.txt
     ```

2. **Navigate to this folder**:
   ```bash
   cd notebooks/evaluation-RQ2/robustness_dbpedia
   ```

3. **Run the notebook**:
   - Open `08_visualize_robustness_dbpedia.ipynb` in Jupyter Notebook or VS Code.
   - Execute the cells sequentially to reproduce the results.

## Notes
- Ensure the required datasets are available in the `datasets` folder.
- Results will be saved in this folder.
