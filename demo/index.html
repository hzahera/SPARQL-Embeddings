Contrastive Learning for Results-Aware SPARQL Embeddings

Two SPARQL queries can look almost the same and return different answers, or look different and return the same answers. We execute a query log once, label query pairs by the overlap of their answers, and fine-tune encoders so that queries sit close when they return similar answers. At query time, only the query text is needed.
