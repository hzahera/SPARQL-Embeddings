# SPARQL Dataset Sampling Pipeline

This directory contains **the pipeline for sampling and filtering unique SPARQL SELECT queries** from the LSQ dataset, and for saving those that return meaningful results from DBpedia.


## Pipeline Notebooks

- `sample_queries.ipynb`:  
  *Fetches SELECT queries from LSQ, removes duplicates, saves to CSV (`unique_select_queries.csv`).*

- `query-DBpedia-and-filter.ipynb`:  
  *Loads unique queries, sends them to DBpedia, saves those with non-empty results to `queries_with_answers.json`.*

## Usage

1. Open `Sampled-LSQ-Dataset/collecting-queries-and-preprocessing.ipynb`.
2. Set SAMPLE_SIZE (or leave sampling defaults) and run the fetch + DBpedia cells to generate `queries_with_answers_sampled.json`.
3. Open `Sampled-LSQ-Dataset/query-similariy-analysis.ipynb` and run cells; it will auto-detect the JSON and run similarity steps.

## Results

This experiment evaluates the similarity between SPARQL queries from successful_queries.json using two complementary metrics:

Jaccard similarity – measures the overlap in query result sets, indicating how similar the returned answers are.

Cosine similarity – measures the semantic similarity of the query text based on sentence embeddings generated by the Qwen/Qwen3-Embedding-0.6B model.

Each query in the dataset is treated as a base query, and other queries are identified as similar if they produce comparable results and/or share structural or semantic patterns.

The output JSON file lists each base SPARQL query along with its most similar queries, showing how closely they align in both returned results (Jaccard score) and semantic meaning (cosine similarity).
